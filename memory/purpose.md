# purpose.md — The Bot Journey

## The One Line Version
Multi-Task Deep Learning Framework for Real-Time Cattle Health, Behavior, and Biometric Monitoring.

## Core Mission
Develop, evaluate, and benchmark deep learning architectures (specifically multi-task learning across individual cattle identification, body condition scoring (BCS), behavior recognition, and spatiotemporal lameness detection) for livestock monitoring under supervisor Dr. Md. Khalilur Rahman at BRAC University.

## Platform Goals & Success Metrics
- Successfully complete and present Phase 2 (P2) undergraduate thesis defense.
- Achieve state-of-the-art multi-task performance across individual identification, BCS assessment, behavior classification, and lameness detection.
- Maintain comprehensive LaTeX thesis documentation, defense presentation materials, QA guides, and reproducible benchmark workspaces for all group members (Hasin, Nusrat, Shouvik, Bithi, Namira).
