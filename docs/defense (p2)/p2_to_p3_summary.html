Team Summary

P2-তে কী হলো, কী ভুল পেলাম, আর P3-তে আমরা কী করতে চাই

এটা আমি আমাদের পুরো P2 কাজ, dataset setup, split, results আর possible P3 direction আবার review করার পরে team-কে explain করার জন্য লিখছি। Multiple high-reasoning AI review, repo audit, dataset inspection আর আমাদের discussion মিলিয়ে এখন directionটা অনেক বেশি clear।

1. P2-তে আমরা আসলে কী করেছিলাম?

P2-তে আমরা একটা Multi-Task Learning (MTL) system বানিয়েছিলাম। একই shared CNN backbone থেকে 4টা আলাদা task predict করার চেষ্টা করেছি: Body Condition Score, Behavior, Lameness আর Cow Identification।

Raw cattle image ↓ Shared CNN backbone ↓ BCS | Behavior | Lameness | Cow ID

মূল idea ছিল 4টা আলাদা model না বানিয়ে common visual features share করা। কিন্তু পরে আমরা বুঝেছি, সব task একই ধরনের visual information চায় না।

2. P2-তে সবচেয়ে বড় conceptual weakness কী ছিল?

P2-তে আমরা model-কে raw cattle image দিয়েছি। সেই image-এর মধ্যে cow-এর পাশাপাশি grass, barn, floor, fence, light, camera background—সবকিছুই ছিল।

Model-কে আমরা explicitly বলিনি কোন pixelগুলো cow, cow-এর কোন অংশ hip, spine, leg, head, hoof, বা cow কোন angle থেকে দেখা হচ্ছে। তাই model পুরো image-এর সব pixel থেকেই feature শিখেছে।

সহজভাবে বললে, model-কে আমরা বলিনি “এই অংশটা cow, আর এই অংশগুলো background”। তাই prediction করার সময় model cow-এর body feature শিখতে পারত, কিন্তু একই সাথে grass, floor, barn, light বা camera angle-এর মতো background pattern-ও ব্যবহার করতে পারত। তখন model হয়তো cow-কে বুঝে prediction করছে না; বরং image-এর সাথে বারবার দেখা কিছু visual pattern মনে রেখে prediction করছে।

তাই P2-তে model-এর জন্য পুরো image-টাই input ছিল। Cow-এর body, background, floor, fence—সব pixel একসাথে training-এ গেছে। আমরা আলাদা করে cow-এর shape, body parts বা anatomy identify করে দিইনি। P3-তে আমরা এই জায়গাটাই improve করতে চাই: আগে model-কে cow কোথায় এবং cow-এর body structure কী সেটা বুঝতে সাহায্য করব, তারপর health-related prediction করাব।

3. কেন shared MTL-এ problem হলো?

BCS

Body Condition

এখানে hip, rump, spine, body shape আর fat condition গুরুত্বপূর্ণ।

Behavior

Activity / Posture

এখানে head position, body posture, movement, feeding বা lying context গুরুত্বপূর্ণ।

Cow ID

Identity

এখানে coat pattern, appearance আর identity-specific visual feature বেশি গুরুত্বপূর্ণ।

এই taskগুলো অনেক different feature চায়। কিন্তু আমরা এগুলোকে অনেকটা একই shared backbone দিয়ে force করেছি। পরে result-এ দেখি negative transfer হয়েছে—এক task-এর জন্য useful feature অন্য task-এর performance খারাপ করেছে।

P2-তে BCS এবং Behavior—দুটোতেই joint MTL training-এর পরে single-task baseline-এর তুলনায় performance খারাপ হয়েছিল।

তাই P2 থেকে একটা important lesson হলো: সব cattle vision task একইভাবে feature share করলে automatically benefit হয় না।

4. Lameness কেন main P3 থেকে বাদ দিচ্ছি?

P2-তে যে lameness dataset ব্যবহার করেছিলাম, পরে সেটা আবার properly inspect করে দেখি data অনেক inconsistent।

একেক video-তে একেক cow, একেক camera angle, কখনো side view, কখনো rear বা diagonal view, আবার কিছু video-তে camera নিজেই move করছে। Cow সবসময় straight line-এ walk করছে না, body crop হয়ে যাচ্ছে, legs পুরো দেখা যাচ্ছে না, perspective-ও consistent না।

সবচেয়ে বড় concern হলো dataset-এর কিছু clip real cattle footage-ও না; কিছু video CGI / Blender / synthetic-looking ছিল। তাই এই data দিয়ে lameness-এর strong scientific claim করা safe না।

তাই আমরা lameness problem বাদ দিচ্ছি না। আমরা শুধু এই weak and inconsistent dataset দিয়ে main P3 experiment করছি না। Better quality lameness data future extension হিসেবে রাখা যাবে।

5. P3-তে primary 3টা task কী থাকবে?

Dataset name শুধু বললে team-এর সবাই বুঝবে না, তাই plain language-এ:

Task 1

Body Condition Scoring

আমাদের main BCS dataset-এ প্রায় 53 হাজার rear-view dairy cow image আছে। প্রতিটা image-এর body condition score label আছে। এই dataset-এর নাম ScienceDB BCS।

Task 2

Behavior Recognition

আমাদের main behavior dataset-এ প্রায় 2.13 লাখ surveillance cattle image আছে। সেখানে walking, standing, feeding, drinking, lying ইত্যাদি 7টা behavior class আছে। Dataset-এর নাম MmCows।

Task 3

Individual Cow Identification

আমাদের main identification dataset-এ 46টা individual cow-এর প্রায় 4.7 হাজার image আছে। Model-এর কাজ কোন cow কোন identity সেটা predict করা। Dataset-এর নাম OpenCows2020।

এছাড়া আরেকটা ছোট BCS dataset আছে Dryad, যেটা secondary comparison বা external evaluation-এ ব্যবহার করা যেতে পারে।

6. P3-তে শুধু cleaner MTL করলেই কি uniqueness হবে?

Panel-এর main criticism ছিল: “Where is the novelty bro, you’re just merging 3/4 models?”

তাই P3-তে শুধু lameness বাদ দিয়ে 3-task MTL করলে system clean হবে, কিন্তু uniqueness problem পুরো solve নাও হতে পারে। এই জায়গা থেকেই আমাদের নতুন cattle-centered idea এসেছে।

7. New idea: Model-কে শুধু pixels না, cow-এর structure বুঝতে শেখানো

Original cattle image ↓ Cow Segmentation / Object Understanding ↓ Cattle Anatomy / Keypoints / Pose ↓ Viewpoint / Angle Awareness ↓ Cattle-Centered Representation ↓ BCS | Behavior | Cow ID

মূল idea হলো health prediction-এর আগে model-কে cattle-specific understanding দেওয়া। Model যেন আগে বুঝে cow কোথায়, তারপর cow-এর body structure কী, তারপর কোন angle থেকে cow-কে দেখা হচ্ছে।

8. Step 1 — Segmentation

Segmentation মানে আমরা শুধু background delete করব—এমন না। বরং model-কে explicitly শেখাব কোন region cow।

আরও interesting option হলো শুধু cow না, দরকার হলে background-এর important object-ও segment করা। যেমন feeder, water trough, floor area, pen boundary—এগুলো Behavior task-এর জন্য useful context হতে পারে।

RGB image ↓ Segment / identify: - Cow - Feeder - Water area - Other useful context ↓ Health model gets structured visual guidance

অর্থাৎ goal হলো background blind করা না; goal হলো image-এর কোন part কী, সেটা model-কে clearer structure হিসেবে দেওয়া।

9. Step 2 — Anatomy / Pose Learning

Cow detect করার পরে আমরা model-কে body anatomy শিখাতে চাই। যেমন head, spine, shoulder, hip, rump, knee, hock, hoof, leg, body contour—এই ধরনের anatomical landmark।

Public cattle pose/keypoint datasets আছে যেখানে 16–20টার মতো body keypoint annotate করা হয়েছে। এগুলো ব্যবহার করে anatomy-aware representation শেখানো সম্ভব।

এতে model শুধু “cow-looking texture” না, body structure আর pose-এর geometry-ও শিখতে পারে।

10. Step 3 — Viewpoint / Angle Awareness

একই cow-এর body part rear view আর side view-তে একইভাবে visible না। তাই angle জানা থাকলে model anatomy-কে better interpret করতে পারে।

Rear view-তে hip, rump, spine BCS-এর জন্য useful হতে পারে। Side view-তে legs, torso, posture Behavior-এর জন্য বেশি useful হতে পারে।

Possible viewpoint classes: Front Rear Left Side Right Side Diagonal

Viewpoint model output downstream health model-এর সাথে feature বা embedding হিসেবে দেওয়া যেতে পারে।

11. তাহলে P3-র stronger research contribution কী হতে পারে?

“Generic raw RGB backbone” থেকে “cattle-centered visual representation”-এ যাওয়া।

অর্থাৎ contribution শুধু multiple task এক model-এ আনা না। আমরা আগে segmentation, anatomy আর viewpoint দিয়ে cattle-specific representation বানাব, তারপর BCS, Behavior আর Identification করব।

এটা panel-এর “just merged models” criticism-এর stronger answer হতে পারে।

12. আমরা কীভাবে prove করব কোন component useful?

আমরা ablation study করতে পারি:

Model A → Raw RGB only Model B → RGB + Segmentation Model C → RGB + Segmentation + Anatomy Model D → RGB + Segmentation + Anatomy + Viewpoint

তারপর BCS, Behavior আর Cow ID—সব task-এ compare করব। তাহলে আমরা শুধু final accuracy দেখব না; বরং কোন extra component আসলে কতটা value দিল সেটা দেখাতে পারব।

13. Dataset audit থেকে আর কী শিখেছি?

BCS dataset এখন ভালো অবস্থায় আছে। Cow identity অনুযায়ী train/validation/test আলাদা রাখা হয়েছে।

Behavior dataset cow-wise split করা হয়েছে, কিন্তু dataset-এ unique cow মাত্র 16টা। তাই robust evaluation-এর জন্য multiple cow-level split বা fold দরকার হতে পারে।

Cow ID dataset-এ একটা important issue পাওয়া গেছে: training set-এর consecutive video frames randomভাবে train আর validation-এ ভাগ হয়ে যেতে পারে। তাই near-duplicate frame দুই জায়গায় চলে যাওয়ার risk আছে। এই split আমরা P3-তে ঠিক করব।

15. Team-এর জন্য এক লাইনের summary

P2-তে আমরা raw cattle image-এর সব pixel সরাসরি CNN-এ দিয়ে 4-task MTL করেছিলাম; পরে negative transfer, weak lameness data, leakage risk আর raw-image shortcut problem ধরা পড়ে। P3-তে cleaner 3-task setup রাখার পাশাপাশি segmentation, cattle anatomy আর viewpoint awareness দিয়ে model-কে cattle-centered understanding দেওয়ার direction investigate করছি, যাতে contribution শুধু model merge করা না হয়ে একটা genuinely cattle-specific visual representation হয়।
