\section*{Abstract}

Continuous precision cattle monitoring requires evaluating body condition scoring (BCS), behavior recognition, and individual re-identification (Re-ID). These heterogeneous tasks rely on different visual information: body morphology, temporal motion, and fine-grained biometric appearance. This thesis investigates cattle-centered visual representations using target localization, foreground masks, and lightweight temporal modeling under leakage-aware single-task and multi-task evaluation protocols.

Matched single-task experiments showed task-dependent benefits. Cattle-centered representations reduced BCS estimation error, improved balanced behavior recognition, and substantially improved open-set Re-ID under the oracle mask condition. In multi-task learning, monolithic hard parameter sharing produced outcome-level degradation across all three tasks. Task-private residual adapters did not consistently mitigate this degradation. During PCGrad training, frequent opposing shared-backbone gradient directions were directly observed, while gradient-projected optimization provided selective recovery, particularly for behavior recognition. Nevertheless, dedicated single-task models remained superior on several primary metrics.

These findings show that shared representations do not automatically benefit heterogeneous cattle-monitoring tasks. Effective unified monitoring therefore requires balancing shared cattle-centered features with task-specific representation capacity and conflict-aware optimization.

\vspace{1em}
\noindent\textbf{Keywords:} cattle monitoring; body condition scoring; behavior recognition; cattle re-identification; cattle-centered representation; multi-task learning; negative transfer.
