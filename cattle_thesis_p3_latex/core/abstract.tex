\section*{Abstract}

Continuous precision cattle health monitoring involves assessing BCS, behavior recognition, and re-ID of cattle. These tasks involve different kinds of visual information such as body morphology, temporal motion, and fine-grained biometric appearance. This work aims to examine cattle-centric visual representation through target localization, segmentation masks, and lightweight temporal modeling under leakage-aware single-task and multi-task settings.

Single-task experiments showed task-specific improvement. The cattle-oriented model provided improved performance of BCS and behavior recognition, while open set Re-ID performance increased with the oracle mask setting. Hard parameter sharing using multi-task learning degraded the results in all the three tasks. Nonetheless, the private residual adapters provided selective improvements but did not consistently improve the degraded results. PCGrad training showed frequently conflicting gradients of the shared backbone. Gradient projection provided a way to recover selectively from the conflicting gradients especially for behavior recognition.

These findings show that shared representations do not automatically benefit heterogeneous cattle-monitoring tasks. Effective unified monitoring therefore requires balancing shared cattle-centered features with task-specific representation capacity and conflict-aware optimization.

\vspace{1em}
\noindent\textbf{Keywords:} cattle monitoring; body condition scoring; behavior recognition; cattle re-identification; cattle-centered representation; multi-task learning; negative transfer.
