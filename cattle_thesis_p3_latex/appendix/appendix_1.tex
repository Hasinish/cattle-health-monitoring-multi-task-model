\section{Prepared SideView Protocols}
The identity-disjoint protocol has 77 training, 11 validation and 22 test cows, with 57,605, 7,225 and 15,430 images. The new baseline instead uses Protocol A's 41 training identities, with Protocol D recording partitions for development. These protocols must not be interchanged when reporting results.\evidence{E06,E19,E20}

The report reconstructs 3,604 recording groups using a 60-second adjacency rule. This is the implemented heuristic; independence claims remain bounded by available metadata and checks. A prepared query/gallery table is not retrieval performance.\evidence{E06}
