\section{Design Process and Methodology Overview}

The study compares different visual representations using task-specific evaluation protocols. Each task has an RGB reference model and a cattle-centered version. These six single-task models establish task-specific performance baselines and serve as the empirical reference for evaluating two multi-task learning paradigms: a monolithic hard-shared control architecture and a modular task-private architecture.

The main design question is what information each task should receive. BCS mainly needs morphology, behavior recognition needs posture and temporal change, and Re-ID needs stable individual appearance. Because of this, the cattle-centered models all focus on the target cow, but they do not use exactly the same preprocessing. Figure~\ref{fig:phase3design} shows the overall comparison, and Table~\ref{tab:runstatus} lists the model configurations. Supporting records are indexed in Appendix~\ref{app:evidence}.

The perception-enhanced models change several things at the same time. The BCS model changes localization, cropping, and mask guidance. The behavior model changes both the spatial representation and temporal aggregation. The Re-ID model changes crop geometry and adds an oracle mask channel. Therefore, these comparisons measure the full model configurations. They do not prove the isolated effect of any one component.

\section{Preliminary Designs and Model Specifications}

\subsection{Representation Alternatives}

The RGB reference models use ImageNet-pretrained ResNet-18 encoders so that the three tasks start from the same practical backbone~\cite{he2016resnet}. The prediction head is different for each task: cumulative ordinal logits for BCS, categorical logits for behavior, and an identity classifier with a retrieval embedding for Re-ID. Keeping the task protocol fixed allows us to compare the RGB and cattle-centered inputs more fairly.

Localization and segmentation were chosen after testing pretrained perception models. The study checked detector return rate and latency, and measured mask overlap where SideView ground-truth masks were available. RT-DETR-L followed by SAM 2.1 gave a practical automatic pipeline for ScienceDB and behavior data. SideView's released masks allowed a separate oracle-guided Re-ID experiment~\cite{zhao2024rtdetr,ravi2024sam2}. Pose and viewpoint were not included in these first paired models because their task usefulness and transfer reliability had not been established at the time. This does not mean that they are rejected as separate later ablations.

\subsection{Baseline RGB Body Condition Scoring}

The BCS baseline uses an ImageNet-initialized ResNet-18 with four independent cumulative threshold logits for five ordered classes. For a class index $y\in\{0,1,2,3,4\}$, the target for threshold $k$ is
\begin{equation}
 t_k=\mathbb{I}(y>k),\qquad k=0,1,2,3.
\end{equation}
If $g_k=\mathbf{w}_k^\top\mathbf{h}+b_k$ is the corresponding logit, the batch loss is
\begin{equation}\label{eq:bcs_loss}
 L_{\mathrm{BCS}}=-\frac{1}{4B}\sum_{i=1}^{B}\sum_{k=0}^{3}
 \left[t_{ik}\log\sigma(g_{ik})+(1-t_{ik})\log(1-\sigma(g_{ik}))\right].
\end{equation}
The predicted class is found by counting how many threshold probabilities are above 0.5. It is then mapped back to the physical BCS scale:
\begin{equation}
 \hat y=\sum_{k=0}^{3}\mathbb{I}(\sigma(g_k)>0.5),\qquad
 \widehat{\mathrm{BCS}}=3.25+0.25\hat y.
\end{equation}
The targets are cumulative, but the model uses independent ordinal binary cross-entropy. Therefore, the method is described as \texttt{ordinal\_bce}, not CORAL, because CORAL uses a different rank-consistency method~\cite{coral2020}. The model was trained for 30 epochs with batch size 64, AdamW, an initial learning rate of $10^{-4}$, weight decay $10^{-4}$, a cosine learning-rate schedule, and seed 42. The checkpoint with the lowest validation MAE was kept.

\subsection{Perception-Enhanced Body Condition Scoring}

The perception-enhanced BCS model first localizes and segments the cow in ScienceDB. RT-DETR-L detects cattle using the COCO cattle class with a confidence threshold of 0.25. If more than one cow is detected, the largest bounding box is selected, and confidence is used to break a tie. The selected box is expanded by 5\% in each direction, clipped to the image boundary, and used for both the RGB crop and the SAM 2.1 prompt. If detection or segmentation fails, the image is recorded as a perception failure and excluded. No artificial replacement input is used.

The RGB crop and binary mask are resized together to $224\times224$. The RGB channels use ImageNet normalization, while the mask stays as an unnormalized binary channel in $\{0,1\}$. The first ResNet-18 convolution is changed from three input channels to four. The pretrained RGB weights are kept, and the new mask-channel weights are initialized using the mean of the RGB filters. The ordinal head, target encoding, loss, training schedule, and augmentation policy otherwise follow the RGB BCS baseline. This adds 3,136 trainable parameters, increasing the model from 11,178,564 to 11,181,700 parameters. The model uses a binary mask channel; it is not a calibrated soft-mask model.

\subsection{Baseline Single-Frame RGB Behavior Recognition}

The behavior baseline uses the midpoint frame of each canonical sample. It uses an ImageNet-pretrained ResNet-18 with a five-class linear classifier. The five classes are Standing, Lying, Feeding, Drinking, and Walking, and the model is trained with cross-entropy loss. CVB samples use the target-tracklet information provided by the dataset, while Kaggle Beef clips already contain one main animal. The selected checkpoint is epoch 25 from the 30-epoch training run, chosen using validation Macro-F1.

This baseline intentionally does not use temporal aggregation. Its purpose is to show how much information one RGB frame can provide under the common five-class label set. For this reason, evaluation includes balanced accuracy and class-specific results as well as overall accuracy. This is especially important because Walking appears only in CVB.

\subsection{Perception-Enhanced Temporal Behavior Recognition}

The temporal behavior model uses eight approximately evenly spaced frames from each labeled interval instead of only the midpoint frame. Its input tensor has shape $[B,8,4,224,224]$. Each time step contains an RGB crop and a binary mask. For CVB, the target-tracklet box at the sampled frame is used to prompt SAM 2.1, and the same box is used for the RGB and mask crops. The model does not replace the target with a nearby cow or with the full image. For the single-cow Beef clips, RT-DETR-L provides the main cow box when available, followed by a positive center prompt to SAM 2.1. If the detector finds no cow, an image-center prompt is used. A sequence is excluded if any required mask is empty or invalid.

The training and validation cache kept 4,271 of 4,465 candidate sequences: 3,641 for training and 630 for validation. It contains 34,168 RGB frames and 34,168 non-trivial binary masks. There were 194 exclusions because of empty-mask failures, and all 145 Walking candidates in training and validation were kept. The held-out test comparison separately kept 780 of 809 samples, including 422 CVB and 358 Beef sequences.

Each frame is passed through a four-channel ResNet-18 to produce a 512-dimensional feature. The sequence $\mathbf{H}\in\mathbb{R}^{B\times8\times512}$ is then transposed for temporal convolution. The first temporal block uses a width-three Conv1D projection from 512 to 256 channels, followed by BatchNorm, GELU, dropout 0.2, and a width-one residual projection. The second width-three block keeps 256 channels and uses the same normalization, activation, and dropout with an identity residual. Adaptive average pooling across time gives one 256-dimensional feature vector, which is passed to the five-class linear head. This is a lightweight residual Conv1D model over sparsely sampled frame features. It is not optical flow, a video transformer, or a deep dilated causal TCN. The full model has 11,903,621 trainable parameters.

\subsection{Baseline RGB Cattle Re-Identification}

The RGB Re-ID baseline follows SideView Protocol A. Representation learning uses 41 cows from the parlor setting only, with 12,753 training images and 2,683 validation images. Evaluation uses 69 different cows. The gallery contains 36,811 parlor images, the barn query set contains 25,260 images from all 69 cows, and the snapshot query set contains 607 images from 63 cows. The cows used for representation learning and evaluation do not overlap.

ResNet-18 produces a raw 512-dimensional feature $\mathbf{h}$. A 41-class linear classifier is trained on this feature with cross-entropy loss. Retrieval uses the L2-normalized version:
\begin{equation}
 \mathbf{z}=\frac{\mathbf{h}}{\lVert\mathbf{h}\rVert_2},\qquad
 \boldsymbol{\ell}=W\mathbf{h}+\mathbf{b}.
\end{equation}
During evaluation, cosine similarity is calculated as the dot product between normalized query and gallery embeddings. Gallery images are ranked for each query, and performance is reported using Rank-$k$ and mean average precision (mAP). The model was trained for 30 epochs, and the validation-selected representation was evaluated once under the held-out Protocol A conditions.

\subsection{Oracle Segmentation-Guided Re-Identification}

The segmentation-guided Re-ID model uses the ground-truth target-cow masks released with SideView. It is therefore an oracle experiment. The non-zero part of the mask is used to define a bounding box, which is expanded by about 5\%. The same coordinates are used to crop the RGB image and the mask, and both are resized to $224\times224$. RGB is ImageNet-normalized, while the mask stays binary in $\{0,1\}$. The RGB image is not multiplied by the mask. The first convolution is changed to accept four channels, and the new mask-channel filters are initialized from the mean RGB weights. The remaining learning and retrieval procedures follow the RGB Re-ID baseline.

This comparison tests whether reliable target-centered cropping and explicit foreground information help cross-setting retrieval. It does not test an automatic segmentation pipeline, and it does not separate the effect of cropping from the effect of the fourth channel. The extra 3,136 weights increase the trainable parameter count from 11,197,545 to 11,200,681.

\section{Data Collection and Preparation}

\subsection{Data Sources and Scientific Roles}

All experiments use existing datasets; no new farm data were collected for this thesis. ScienceDB is the main BCS dataset, CVB and Kaggle Beef form the main behavior dataset, and SideViewCows2026 is the main Re-ID dataset. External datasets have separate stress-test roles and are not described as evaluated unless supporting results exist. Table~\ref{tab:datasets} summarizes these roles.

\input{tables/dataset_summary}

ScienceDB contains 53,566 RGB images across five BCS values from 3.25 to 4.25. Its released metadata do not contain verified biological cow IDs. Therefore, the 5,653 repaired connected burst groups are the strongest safe grouping unit available. ScienceDB evaluation is described as burst-group-disjoint, passage-disjoint, or sequence-safe. It is not described as unseen-cow evaluation.

The behavior manifest contains 2,481 CVB segments and 2,793 Beef clips. Together, they form 267 protected groups and 5,274 samples. CVB is grouped by source video, while Beef is grouped by recording-session or source-video provenance. Walking appears only in CVB. Therefore, the main behavior evaluation is source/session-group-disjoint rather than cow-disjoint, and overall accuracy by itself is not enough.

SideView contains 80,260 RGB images, 80,260 matching binary masks, and 110 biological cow identities. Protocol A separates 41 cows used for representation learning from 69 cows used for evaluation. This supports an identity-disjoint interpretation for the Re-ID comparisons, unlike the BCS and behavior protocols.

\subsection{Label Harmonization and Split Protection}

ScienceDB keeps its original physical BCS values. CVB labels for resting-standing, resting-lying, grazing, drinking, and walking are mapped to the five common behavior classes. Beef contributes stand, lie, eat, and drink, while rumination is excluded. This label mapping is fixed before evaluation. SideView cow identities are used only in their assigned learning or evaluation role.

\input{tables/split_summary}

The splits protect the strongest available source of provenance. ScienceDB keeps each connected burst group inside one partition. All CVB segments from the same source video stay in one partition, and all Beef clips from the same recording session stay together. SideView Protocol A separates cow identities between learning and evaluation and also defines the acquisition setting of the gallery and queries. The implemented checks found no forbidden group or identity overlap. However, this does not prove that every possible form of leakage has been removed.

\subsection{Perception Feasibility and Component Selection}

Before choosing the perception pipeline, we compared several off-the-shelf components. The assessment separated output-return rate from actual accuracy and measured mask overlap only where ground truth was available. The results supported RT-DETR-L and SAM 2.1 as practical components. They also showed that getting a valid output from a perception model does not automatically mean that the output contains the anatomy needed by the downstream task.

\input{tables/perception_results}

Pose was not included in the first paired task configurations. A small manual review on ScienceDB showed unreliable results on rear-view images, and the available landmark set did not directly describe the intended BCS anatomy. A separate real-cattle viewpoint classifier reached 86.26\% accuracy, 84.96\% balanced accuracy, and 0.8573 Macro-F1 on its own held-out test of 131 images. Viewpoint was not included in the first paired task models because its downstream transfer had not been validated at that time. Camera identity was not used as a replacement for viewpoint. These statements describe the design choice for the original paired models; they do not mean that pose or viewpoint is permanently rejected.

\section{Implementation of Selected Design}

Preprocessing, spatial feature extraction, temporal sequence aggregation, and multi-task optimization were implemented using PyTorch, Torchvision, OpenCV, and the Ultralytics perception interface. Deterministic CSV manifests define all image samples, biological groups, and split partitions. Checkpoint selection was governed strictly by validation-set objectives, with held-out test sets fully isolated from training and model selection. Machine-readable manifests record all configuration parameters, per-epoch loss trajectories, checkpoint checksums, and evaluation rankings to ensure strict scientific reproducibility.

\subsection{Monolithic Hard-Shared Multi-Task Control Architecture}

The monolithic hard-shared multi-task control (denoted as E1) establishes the baseline for joint parameter sharing across the three target domains. In this architecture, all three tasks share exactly one four-channel ResNet-18 spatial feature extractor, which accounts for 11,179,648 parameters (93.74\% of the total model capacity).

The model accepts task-specific input tensors whose spatial dimensions are standardized to $224 \times 224$ pixels across four channels, comprising three ImageNet-normalized RGB channels and one unnormalized binary cow mask:
\begin{align}
 \mathbf{X}_{\mathrm{BCS}} &\in \mathbb{R}^{B_{\mathrm{BCS}} \times 4 \times 224 \times 224}, \\
 \mathbf{X}_{\mathrm{Beh}} &\in \mathbb{R}^{B_{\mathrm{Beh}} \times 8 \times 4 \times 224 \times 224}, \\
 \mathbf{X}_{\mathrm{ReID}} &\in \mathbb{R}^{B_{\mathrm{ReID}} \times 4 \times 224 \times 224}.
\end{align}
The shared spatial backbone maps each four-channel frame to a 512-dimensional embedding $\mathbf{h} \in \mathbb{R}^{512}$. Each task then routes this representation to its task-specific prediction head:
\begin{enumerate}
 \item \textbf{Body Condition Scoring}: The shared feature $\mathbf{h}$ is passed to the cumulative ordinal linear head (2,052 trainable parameters), producing four independent threshold logits $g_k = \mathbf{w}_k^\top \mathbf{h} + b_k$ for $k \in \{0, 1, 2, 3\}$. The ordinal binary cross-entropy loss $L_{\mathrm{BCS}}$ is computed following Equation~\eqref{eq:bcs_loss}.
 \item \textbf{Cattle Behavior Recognition}: Each of the 8 frames in an input video sequence passes through the identical shared four-channel ResNet-18 spatial backbone, yielding a temporal sequence of frame embeddings $\mathbf{H} \in \mathbb{R}^{B_{\mathrm{Beh}} \times 8 \times 512}$. This sequence is processed by the temporal convolutional network (TCN) head (723,973 trainable parameters), which applies two width-three Conv1D residual blocks with 256 channels, BatchNorm, GELU, and dropout (0.2), followed by temporal adaptive average pooling to 256 dimensions and a 5-class linear classifier optimized with categorical cross-entropy loss $L_{\mathrm{Beh}}$.
 \item \textbf{Individual Cattle Re-Identification}: During representation training across the 41 parlor training identities, the shared 512-dimensional feature $\mathbf{h}$ is passed to a 41-class linear classifier with bias (21,033 trainable parameters) optimized using cross-entropy loss $L_{\mathrm{ReID}}$. For open-set retrieval evaluation across unseen cows, unit L2-normalized embeddings $\mathbf{z} = \mathbf{h} / \lVert\mathbf{h}\rVert_2$ are extracted.
\end{enumerate}
The monolithic hard-shared multi-task control contains exactly 11,926,706 trainable parameters.

\subsection{Modular Task-Private Multi-Task Architecture}

The modular task-private multi-task architecture (denoted as E3) evaluates whether introducing task-private capacity can mitigate negative transfer while retaining a shared visual backbone. To isolate the effect of modular routing, this architecture preserves the exact same components and training conditions as the hard-shared control:
\begin{itemize}
 \item The identical four-channel ResNet-18 spatial feature extractor (11,179,648 parameters);
 \item The identical task-specific heads: BCS ordinal head (2,052 parameters), Behavior 1D TCN head (723,973 parameters), and Re-ID classification head (21,033 parameters);
 \item The identical input tensor shapes, preprocessing pipelines, training datasets, batch sizes, loss functions, and optimization hyperparameters.
\end{itemize}

The architectural modification consists of inserting one independent residual bottleneck adapter between the shared 512-dimensional representation $\mathbf{h}_{\mathrm{shared}} \in \mathbb{R}^{512}$ and each respective task head. For task $t \in \{\mathrm{BCS}, \mathrm{Beh}, \mathrm{ReID}\}$, the adapter consists of:
\begin{enumerate}
 \item A linear down-projection from 512 to 128 dimensions with weights $\mathbf{W}_{\mathrm{down}}^{(t)} \in \mathbb{R}^{128 \times 512}$ and bias $\mathbf{b}_{\mathrm{down}}^{(t)} \in \mathbb{R}^{128}$;
 \item Layer normalization over the 128-dimensional bottleneck;
 \item A GELU activation function followed by dropout ($p = 0.1$);
 \item A linear up-projection from 128 back to 512 dimensions with weights $\mathbf{W}_{\mathrm{up}}^{(t)} \in \mathbb{R}^{512 \times 128}$ and bias $\mathbf{b}_{\mathrm{up}}^{(t)} \in \mathbb{R}^{512}$.
\end{enumerate}
The adapter output $\Delta\mathbf{h}_t \in \mathbb{R}^{512}$ is added residually to the shared spatial representation to produce the task-adapted feature $\mathbf{h}_t$:
\begin{equation}
 \mathbf{h}_t = \mathbf{h}_{\mathrm{shared}} + \Delta\mathbf{h}_t.
\end{equation}
In the temporal behavior model, this adapter operates frame-wise on each of the 8 temporal feature vectors before the adapted sequence $\mathbf{H}_{\mathrm{Beh}} \in \mathbb{R}^{B_{\mathrm{Beh}} \times 8 \times 512}$ is routed to the temporal convolutional network.

Each task-private adapter contains exactly 131,968 parameters, yielding 395,904 total private parameters across the three tasks (3.21\% of the model's total parameters). The modular multi-task architecture comprises 12,322,610 trainable parameters, representing an increase of 395,904 parameters (+3.32\% relative capacity) over the hard-shared control.

\subsubsection{Identity Initialization of Residual Adapters}

The up-projection layer of each task adapter is initialized with zero weights and zero biases:
\begin{equation}
 \mathbf{W}_{\mathrm{up}}^{(t)} = \mathbf{0}, \qquad \mathbf{b}_{\mathrm{up}}^{(t)} = \mathbf{0}.
\end{equation}
At step zero of training, this ensures that the adapter contribution is strictly zero:
\begin{equation}
 \Delta\mathbf{h}_t = \mathbf{0} \implies \mathbf{h}_t = \mathbf{h}_{\mathrm{shared}}.
\end{equation}
This initialization does not imply inheriting representations from a pretrained hard-shared checkpoint; rather, it guarantees that at the start of joint training, each task-specific head receives the direct, unperturbed output of the modular model's own shared backbone. Task-private feature specialization $\Delta\mathbf{h}_t$ then develops progressively as gradient updates accumulate during training.

\subsection{Multi-Task Joint Optimization Protocol}

Because cattle datasets from different farms and recording modalities do not contain overlapping annotations across body condition, behavior sequences, and individual identities, joint multi-task training cannot employ single multi-label batches. Instead, an interleaved mini-batch schedule is executed.

Each optimization step is structured as a multi-task super-step comprising three sequential forward and backward passes:
\begin{enumerate}
 \item \textbf{BCS mini-batch}: A batch of $B_{\mathrm{BCS}} = 64$ samples is passed through the model. The ordinal binary cross-entropy loss $L_{\mathrm{BCS}}$ is computed, and gradients are backpropagated into the active parameters.
 \item \textbf{Behavior mini-batch}: A batch of $B_{\mathrm{Beh}} = 8$ video sequences (64 total frames) is passed through the model. The categorical cross-entropy loss $L_{\mathrm{Beh}}$ is computed, and gradients are backpropagated and accumulated.
 \item \textbf{Re-ID mini-batch}: A batch of $B_{\mathrm{ReID}} = 32$ images is passed through the model. The identity cross-entropy loss $L_{\mathrm{ReID}}$ is computed, and gradients are backpropagated and accumulated.
 \item \textbf{Parameter update}: The optimizer executes a single parameter update using the accumulated gradients.
\end{enumerate}

Equal task weighting is enforced throughout training:
\begin{equation}
 w_{\mathrm{BCS}} = w_{\mathrm{Behavior}} = w_{\mathrm{ReID}} = 1.0.
\end{equation}
Training runs for 30 epochs with 537 super-steps per epoch (16,110 total super-steps). Optimization uses AdamW with an initial learning rate of $\eta_0 = 10^{-4}$, weight decay of $10^{-4}$, and a cosine annealing learning-rate schedule decaying to $\eta_{\min} = 10^{-6}$.

Model checkpoint selection is determined strictly by minimizing the predefined mean validation loss objective:
\begin{equation}
 L_{\mathrm{MTL,val}} = \frac{1}{3}\left( L_{\mathrm{BCS,val}} + L_{\mathrm{Behavior,val}} + L_{\mathrm{ReID,val}} \right).
\end{equation}
All canonical held-out test splits and unseen identity sets are strictly quarantined from model selection, hyperparameter tuning, and threshold calibration.

\subsection{Architectural Gradient Isolation and Claim Boundaries}

The mathematical distinction in gradient routing between the monolithic and modular multi-task models is formal and structural:
\begin{itemize}
 \item In the \textbf{monolithic hard-shared model}, the parameter vector of the shared backbone $\boldsymbol{\theta}_{\mathrm{shared}}$ directly receives gradient contributions from all three task loss functions:
 \begin{equation}
  \mathbf{g}_{\mathrm{shared}} = \nabla_{\boldsymbol{\theta}_{\mathrm{shared}}} L_{\mathrm{BCS}} + \nabla_{\boldsymbol{\theta}_{\mathrm{shared}}} L_{\mathrm{Beh}} + \nabla_{\boldsymbol{\theta}_{\mathrm{shared}}} L_{\mathrm{ReID}}.
 \end{equation}
 Each task head $\boldsymbol{\theta}_{\mathrm{head}}^{(t)}$ receives gradients solely from its own loss $L_t$.
 \item In the \textbf{modular task-private model}, the shared backbone $\boldsymbol{\theta}_{\mathrm{shared}}$ intentionally receives accumulated gradients from all three tasks through the residual connection:
 \begin{equation}
  \mathbf{g}_{\mathrm{shared}} = \sum_{t \in \{\mathrm{BCS}, \mathrm{Beh}, \mathrm{ReID}\}} \nabla_{\boldsymbol{\theta}_{\mathrm{shared}}} L_t.
 \end{equation}
 In contrast, each task-private adapter $\boldsymbol{\theta}_{\mathrm{adapter}}^{(t)}$ and task head $\boldsymbol{\theta}_{\mathrm{head}}^{(t)}$ receive gradient signals strictly from their corresponding task loss $L_t$, with $\nabla_{\boldsymbol{\theta}_{\mathrm{adapter}}^{(t)}} L_{t'} = \mathbf{0}$ for all $t' \neq t$.
\end{itemize}

This gradient isolation is an architectural routing property that prevents direct gradient updates from one task head from altering the private adapter parameters of another task. It does not constitute theoretical proof that gradient conflict in the shared backbone is eliminated, nor does it guarantee that negative transfer will be prevented. The practical consequences of this routing structure on generalization across the three target domains remain an empirical question evaluated in Chapter~5.

\subsection{Evaluation Metrics and Protocol Harmonization}

BCS is evaluated with physical-score MAE, exact accuracy (Acc@0), accuracy within one adjacent class or $\pm0.25$ BCS units (Acc@1), balanced accuracy, and Macro-F1. For $N$ samples,
\begin{equation}
 \mathrm{MAE}_{\mathrm{BCS}}=\frac{1}{N}\sum_{i=1}^{N}|s_i-\hat{s}_i|.
\end{equation}

Behavior evaluation reports overall accuracy, balanced accuracy, Macro-F1, per-class precision, recall, and F1, and source-specific metrics. Balanced accuracy is the mean recall over the five classes, which provides a calibrated assessment across unbalanced source distributions.

For Re-ID, Rank-$k$ measures the percentage of queries that return at least one correct identity within the top-$k$ gallery retrieval results. Average precision summarizes ranking quality for each individual query, and mAP is the mean across all evaluated queries. Barn-to-Parlor and Snapshots-to-Parlor queries are evaluated separately against the 36,811-image parlor gallery.

To maintain strict scientific comparability, the monolithic hard-shared and modular multi-task models are evaluated on the exact matched held-out test populations established for the single-task reference models: 7,549 ScienceDB test images for BCS, 780 retained video sequences for behavior recognition, and 69 unseen cattle identities under SideView Protocol A (25,260 barn queries and 607 snapshot queries).
